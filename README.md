📌 Sobre o Projeto

O RachaAí é um aplicativo criado para facilitar a divisão de despesas entre pessoas que moram juntas, viajam em grupo ou compartilham gastos frequentes.

O objetivo do aplicativo é evitar conflitos causados por contas esquecidas, valores incorretos e cobranças confusas, oferecendo uma experiência simples, rápida e intuitiva.

🎯 Persona

O protótipo foi projetado principalmente para:

Estudantes que moram em repúblicas;
Amigos que dividem apartamento;
Pessoas que organizam viagens em grupo;
Usuários que compartilham despesas recorrentes.
🧠 Heurística de Nielsen em Foco
Visibilidade do Status do Sistema

O protótipo prioriza mostrar claramente:

Quem deve;
Quanto deve;
Qual conta foi paga;
Status dos pagamentos;
Saldo total do grupo.

O usuário sempre consegue visualizar rapidamente a situação financeira do grupo sem precisar navegar excessivamente.

📱 Telas Desenvolvidas

O protótipo contém as seguintes telas:

Dashboard de Grupos
Detalhes do Grupo
Adicionar Gasto
Scanner de Nota Fiscal
Extrato de Dívidas
Confirmação de Pagamento
🔄 Fluxo de Tarefa
Cadastro de uma conta de luz dividida entre 3 pessoas
Passo 1

O usuário acessa o grupo "Casa".

Passo 2

Clica no botão “Adicionar Gasto”.

Passo 3

Insere:

Nome da conta: “Conta de Luz”
Valor total: R$ 300,00
Passo 4

Seleciona os participantes:

João
Maria
Carlos
Passo 5

Escolhe o tipo de divisão:

Divisão igualitária.
Passo 6

O sistema calcula automaticamente:

R$ 100,00 para cada pessoa.
Passo 7

O usuário confirma o cadastro.

Passo 8

O sistema atualiza o saldo geral e mostra:

Quem deve;
Quanto deve;
Para quem deve pagar.
🎨 Objetivos de UX

O protótipo foi desenvolvido com foco em:

Facilidade de uso;
Clareza visual;
Redução de erros;
Navegação simples;
Agilidade em tarefas repetitivas.
